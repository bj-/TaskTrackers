# 0002. Один репозиторий для всех трекеров, папка на каждый трекер

- **Статус:** принято
- **Дата:** 2026-10-12
- **Участники:** bj, Claude

## Контекст

Есть workflow для YouTrack, планируются скрипты для Jira и, возможно, других трекеров.
Отдельный репозиторий на каждый трекер дробит контекст и дублирует `docs/`.

## Решение

Репозиторий `TaskTrackers`: папка верхнего уровня на каждый трекер (`YouTrack/`, `Jira/`, …) со своим `CLAUDE.md`;
общие `CLAUDE.md` и `docs/` (статус, идеи, решения) — в корне. Собранные архивы (`*.zip`) в git не хранятся.

## Альтернативы

- Отдельный репозиторий на трекер — больше накладных расходов, общие решения пришлось бы дублировать.
- Разделение по назначению (workflow / интеграции / отчёты) — у трекеров разные API и форматы, общий код маловероятен.

## Последствия

- В `STATUS.md` и журнале задачи помечаются трекером (`[YouTrack]`, `[Jira]`).
